# Webprogrammierung / Lösung / Web-Visitenkarte

Dies ist die **Musterlösung** zur Aufgabe „Web-Visitenkarte" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *HTML und CSS*.

Eine persönliche Web-Visitenkarte wird als einfache HTML/CSS-Seite umgesetzt.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
